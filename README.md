# REEVA Launching Soon — Spring Edition

A bright, luxury 2D-motion launch experience for REEVA using the final supplied logo and the approved royal invitation concept.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

1. Upload all files to the root of the GitHub repository.
2. In **Settings → Pages**, set the source to **GitHub Actions**.
3. Push or commit to `main`.
4. Open **Actions** and wait for `Deploy REEVA to GitHub Pages` to complete.

The subscription form currently validates and displays a confirmation state. Connect it to Formspree, Supabase, Firebase or another backend before collecting live customer data.
